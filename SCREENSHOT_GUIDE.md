# Riskora Screenshot Guide

1. Start the app: `python app.py`
2. Open http://localhost:5000/
3. Capture the landing page.
4. Register a user and sign in.
5. Upload a supportive sample file such as `notes.txt`.
6. Capture the assessment result screen.
7. Open the cloud storage page to show local-only or configured state.
8. Capture the history and audit log screens.
9. Save images in a presentation folder for academic demonstration.
